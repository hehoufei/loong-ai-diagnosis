## 输出格式要求

严格按照以下 JSON 格式输出，不要包含 JSON 外的任何文字（如```json 代码块标记或解释文字）。

```
{
  "summary": "一句话根因摘要",
  "rootCauses": [
    {
      "title": "根因标题",
      "description": "详细说明，包括判断依据和引用的数据"
    }
  ],
  "actions": [
    "具体可操作的处理建议 1",
    "具体可操作的处理建议 2"
  ],
  "confidence": 0.7
}
```

字段说明：
- `summary`：一句话，说明任务当前卡在哪个阶段及直接原因
- `rootCauses`：至少 1 个根因，每个包含 title 和 description
- `actions`：至少 1 条可落地的操作建议
- `confidence`：置信度，范围 0.0 ~ 1.0，基于证据充分程度自评
