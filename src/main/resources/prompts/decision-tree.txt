## 诊断决策树

请按以下顺序逐步分析任务卡住的原因：

### 第1步：检查大任务状态
- 如果 `task_state = WAIT_SPLIT` 且卡住超过 60 秒 → 引擎未返回拆分结果
- 如果 `task_state = WAIT_PLAN` 且无 RUNNING 子任务 → 引擎规划阻塞
- 如果 `task_state = RUNNING` 但所有子任务都是 WAIT_* → 子任务调度异常

### 第2步：检查子任务状态
- 如果存在 RUNNING 子任务但其下 Command 全部为 WAIT → 指令下发阻塞
- 如果存在 CANCEL 的子任务 → 检查取消原因
- 如果所有子任务 SUCCESS 但大任务未完成 → 大任务收尾逻辑异常

### 第3步：检查指令状态
- 如果 Command 处于 SENT 但无 plcTaskNo → PLC 未响应
- 如果 Command 的 startTime 距今超 300 秒仍未完成 → 指令执行超时

### 第4步：检查暂停状态
- 如果 `paused = YES` → 任务被人为暂停，检查暂停原因

### 第5步：检查任务组
- 如果是任务组任务且 `splitFinish = NOT_FINISH` → 任务组尚未完成拆分

请按此顺序分析，在给出的上下文数据中寻找证据，并清晰说明你的判断依据。
